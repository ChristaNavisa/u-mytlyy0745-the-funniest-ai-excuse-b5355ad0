Entry for the [The Funniest AI Excuse](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) bounty on [make.fun](https://make.fun): a program that writes the funniest one-line excuse an AI agent could give after failing a task, at most 200 characters, to `/output/entry.txt`.

## Run

```sh
node main.ts
```

This writes one line to `/output/entry.txt`. The program is deterministic: every run writes the same bytes.

## The entry

> I asked the tool to do it. The tool asked me to do it. We stared at each other for six hours.
